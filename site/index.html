>_ OmniDev

Ask your Mac anything, and let it do the work.

A native macOS app. A local Gemma 4 model reads your files, including your screenshots, answers with citations, and can edit code and run your tests. Nothing leaves your machine: no account, no API key, no bill.

Download for macOS View source

Free and MIT licensed. Universal binary for Apple silicon and Intel. Builds are unsigned, so the first launch needs right-click then Open.

Agent mode

What it does

Ask your files

Index your Desktop, Documents and Downloads. Notes, PDFs, Office and iWork docs, code, and screenshots read with on-device OCR. Answers cite the file they came from.

Agent mode

It reads, edits, runs your tests and reports back, asking permission before touching anything outside the folders you trust.

Point at one file

Ask about a single document, screenshot or PDF with no indexing at all. Nothing is stored.

Serves other tools

An MCP server exposes the same local index and model to Claude Code, Claude Desktop and Cursor, still fully offline.

What it will never do

  • Never index your secrets. Keys, keychains, browser profiles, password vaults, .env files and shell histories are refused before they are opened, even if you add the folder above them.
  • Never delete your work. The agent has no delete tool, commands that remove files are refused, and overwriting a file always asks first. Every change is backed up and restorable.
  • Never phone home. Embeddings and generation run on your machine. There is no telemetry and no account.
  • Never hang on iCloud. Files stored in the cloud with no local copy are skipped and reported, never silently downloaded.

Requirements

  • macOS on Apple silicon or Intel, with Ollama for the local model. Onboarding installs the model for you.
  • About 8 GB of disk for the default model. 16 GB of RAM recommended; a lighter model is offered on 8 GB machines.
  • Optional: set a Gemini key to use a hosted model instead. offline by default
